# LLM Benchmarks

Tests and research on how language models and agents handle web design work. Each study is self-contained and documents its own method, data and limits.

## Studies

| Study | Question | Status | Report |
|---|---|---|---|
| [Token Naming Instinct](studies/2026-10-token-naming/) | When five models name the same 500 design tokens blind, which names do they agree on? | Complete | [HTML](reports/2026-10-token-naming/report.html) · [Markdown](reports/2026-10-token-naming/report-first-edition.md) · [Dataset](reports/2026-10-token-naming/dataset.zip) |

## Layout

```
studies/    one folder per study, dated. Prompts, raw responses, scripts, notes, whatever the study needs.
reports/    the published output of each study: the report and a dataset archive
```

Studies differ in method and structure. Read each study's own README before using its data.
